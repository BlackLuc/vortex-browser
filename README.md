# Vortex

A minimal tabbed web browser built with [Electron](https://www.electronjs.org/).

## Run

```bash
cd browser
npm install
npm start
```

## Features

- Tabbed browsing (new tab, close tab, switch tabs)
- Back / Forward / Reload / Home buttons
- Address bar with URL or search (Google)
- Page title on tabs
- Opens popups in new tabs
